Haneul repositories are open source and welcome community contributions.

This page describes how to contribute to Haneul, and provides additional information about participating in the Haneul community.

## Join the community {#join-the-community}

To connect with the Haneul community, join our [Discord](https://discord.gg/haneul).

## Open issues {#open-issues}

To report an issue with Haneul, [create an issue](https://github.com/GeunhwaJeong/haneul/issues/new/choose) in the GitHub repo. Click **Get started** to open a template for the type of issue to create.

## Fork Haneul to contribute {#fork-haneul-contribute}

To contribute to Haneul source code or documentation, you need only a GitHub account. You can commit updates and then submit a PR directly from the GitHub website, or create a fork of the repo to your local environment and use your favorite tools to make changes. Always submit PRs to the `main` branch.

See [Haneul Environment Setup](/references/contribute/haneul-environment) for instructions on forking the Haneul repository, if necessary.

## Contribute through the Haneul Improvement Proposal (SIP) process {#SIP}

The Haneul Network is an open source, decentralized, and permissionless protocol that welcomes community contributions. If you have an idea regarding a core protocol upgrade, the best way to make your voice heard is by submitting a Haneul Improvement Proposal (SIP). For more information on SIPs, see [Contribute to Haneul through SIPs](https://blog.haneul.io/haneul-improvement-proposals-sips/).
