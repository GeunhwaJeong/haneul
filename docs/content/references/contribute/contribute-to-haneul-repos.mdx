Haneul repositories are open source and welcome community contributions.

This page describes how to contribute to Haneul, and provides additional information about participating in the Haneul community.

## Join the community {#join-the-community}

To connect with the Haneul community, join our [Discord](https://discord.gg/haneul).

## Open issues {#open-issues}

To report an issue with Haneul, [create an issue](https://github.com/GeunhwaJeong/haneul/issues/new/choose) in the GitHub repo. Click **Get started** to open a template for the type of issue to create.

## Fork Haneul to contribute {#fork-haneul-contribute}

To contribute to Haneul source code or documentation, you need only a GitHub account. Follow these steps to submit a contribution:

1. Fork the [GeunhwaJeong/haneul](https://github.com/GeunhwaJeong/haneul) repository by clicking **Fork** on the GitHub page.
2. Clone your fork locally:
   ```sh
   $ git clone https://github.com/YOUR_USERNAME/haneul.git
   ```
3. Create a feature branch from `main`:
   ```sh
   $ git checkout -b your-branch-name main
   ```
4. Make your changes and commit them with a descriptive message.
5. Push your branch to your fork:
   ```sh
   $ git push origin your-branch-name
   ```
6. Open a pull request from your branch to the `main` branch of [GeunhwaJeong/haneul](https://github.com/GeunhwaJeong/haneul/compare).

Always submit PRs to the `main` branch. See [Haneul Environment Setup](/references/contribute/haneul-environment) for additional instructions on configuring your local environment.

## Contribute through the Haneul Improvement Proposal (SIP) process {#SIP}

The Haneul Network is an open source, decentralized, and permissionless protocol that welcomes community contributions. If you have an idea regarding a core protocol upgrade, submit a [Haneul Improvement Proposal (SIP)](https://sips.haneul.io). For more information on the SIP process, see [Contribute to Haneul through SIPs](https://blog.haneul.io/haneul-improvement-proposals-sips/).
