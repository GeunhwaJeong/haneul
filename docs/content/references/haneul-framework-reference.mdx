The Haneul Framework includes the core onchain libraries for Move developers. These libraries provide the types and functions used to define objects, manage ownership, handle coins, emit events, and interact with other system-level features.

Browse the reference in either of the following formats:

- [Haneul Framework Reference docs](https://docs.haneul.io/references/framework/) - searchable HTML reference generated from source
- [Haneul GitHub repo](https://github.com/GeunhwaJeong/haneul/tree/main/crates/haneul-framework/docs) - Markdown format in the repository

The framework is organized into several packages:

- **`haneul-framework`** - Core types like `object`, `transfer`, `coin`, `event`, `clock`, and `dynamic_field`
- **`haneul-system`** - Validator set, staking, and governance modules
- **`move-stdlib`** - Standard Move library with `vector`, `option`, `string`, and other foundational types
