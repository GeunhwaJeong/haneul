Use the `HaneulnsClient` that you previously created to query onchain data.

## Query a name record

You can query a name record's latest state by calling the `getNameRecord` method on the `HaneulnsClient` instance.

```js
const nameRecord = await haneulnsClient.getNameRecord('demo.haneul');
console.log(nameRecord);

// Example output
// {
//   name: 'demo.haneul',
//   nftId: '0xMyNftId',
//   targetAddress: '0xTargetAddress',
//   expirationTimestampMs: '1746018571863',
//   data: {
//      avatar: '0xAvatarObjectId',
//      contentHash: 'content',
//      walrusSiteId: '0xWalrusSiteId',
//   },
//   avatar: '0xAvatarObjectId',
//   contentHash: 'content',
//   walrusSiteId: '0xWalrusSiteId',
// }
```

## Query active pricing

Call the `getPriceList` method on the `HaneulnsClient` instance to query the active names price list.

```js
const priceList = await haneulnsClient.getPriceList();
console.log(priceList);

// ([domain_length_from, domain_length_to]: price. Prices are in USDC GEUNHWA; 1 USDC = 1_000_000 GEUNHWA)
// Example output:
// {
// 	[ 3, 3 ] => 500000000,
// 	[ 4, 4 ] => 100000000,
// 	[ 5, 63 ] => 20000000
// }
```

## Query active renewal pricing

Call the `getRenewalPriceList` method on the `HaneulnsClient` instance to query the active renewal price list.

```js
const renewalPriceList = await haneulnsClient.getRenewalPriceList();
console.log(renewalPriceList);

// ([domain_length_from, domain_length_to]: price. Prices are in USDC GEUNHWA; 1 USDC = 1_000_000 GEUNHWA)
// Example output:
// {
// 	[ 3, 3 ] => 500000000,
// 	[ 4, 4 ] => 100000000,
// 	[ 5, 63 ] => 20000000
// }
```
