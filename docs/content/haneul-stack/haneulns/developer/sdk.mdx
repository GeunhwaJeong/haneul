Use the HaneulNS SDK to interact with the Haneul Name Service. Query HaneulNS data in a usable way and build transactions that interact with service names.

## Installation

<Tabs>
    <TabItem label="Using @haneullabs/haneul" value="haneul">
    To use with the latest version of the TypeScript SDK, install using:
    ```bash npm2yarn
    $ npm i @haneullabs/haneulns
    ```
    </TabItem>
    <TabItem label="Using @haneullabs/haneul.js" value="haneuljs">
    To use with the older version (prior to 1.x) of the TypeScript SDK (0.54.1), install using:
    ```bash npm2yarn
    $ npm i @haneullabs/haneulns@0.0.3
    ```
    </TabItem>
</Tabs>

## `HaneulnsClient`

`HaneulnsClient` is the base for all HaneulNS functionality.

:::info

You should keep only 1 instance of `HaneulnsClient` throughout your app, API, or script. For example, in React, you should use a context to provide the client.

:::

## Initialize a `HaneulnsClient`

:::caution

Always keep the dependency updated so you get the latest constants. If you do not, some of your transactions might fail to build.

:::

You can initialize a `HaneulnsClient` by either providing the active network (`mainnet` or `testnet`),
or by passing in the constants (usable for any network).

<Tabs groupId='initializer'>

<TabItem label="Network initializer" value='network'>
```js
import { HaneulnsClient } from '@haneullabs/haneulns';
import { getFullnodeUrl, HaneulClient } from '@haneullabs/haneul/client';

// You need a Haneul client. You can re-use the Haneul client of your project
// (it's not recommended to create a new one).
const client = new HaneulClient({ url: getFullnodeUrl('testnet') });

// Now you can use it to create a HaneulNS client.
const haneulnsClient = new HaneulnsClient({
	client,
	network: 'testnet',
});
```
</TabItem>

<TabItem label="Constants initializer" value='constants'>
