Use the HaneulNS SDK to interact with the Haneul Name Service. Query HaneulNS data in a usable way and build transactions that interact with service names.

## Installation

<Tabs>
    <TabItem label="Using @haneullabs/haneul" value="haneul">
    To use with the latest version of the TypeScript SDK, install using:
    ```bash npm2yarn
    $ npm i @haneullabs/haneulns
    ```
    </TabItem>
    <TabItem label="Using @haneullabs/haneul.js" value="haneuljs">
    To use with the older version (prior to 1.x) of the TypeScript SDK (0.54.1), install using:
    ```bash npm2yarn
    $ npm i @haneullabs/haneulns@0.0.3
    ```
    </TabItem>
</Tabs>

## The `haneulns` client extension

The `haneulns()` extension adds HaneulNS functionality to any Haneul client, exposed under `client.haneulns`.

:::info

You should keep only 1 extended client throughout your app, API, or script. For example, in React, you should use a context to provide the client.

:::

## Attach the extension

:::caution

Always keep the dependency updated so you get the latest constants. If you do not, some of your transactions might fail to build.

:::

Attach HaneulNS to a Haneul client with the `haneulns()` extension. Pass no arguments to use the built-in constants for Mainnet and Testnet, or pass a `packageInfo` object to target any other deployment.

<Tabs groupId='initializer'>

<TabItem label="Network initializer" value='network'>
```js
import { haneulns } from '@haneullabs/haneulns';
import { HaneulGrpcClient } from '@haneullabs/haneul/grpc';

// Re-use the Haneul client of your project rather than creating a new one.
const client = new HaneulGrpcClient({
	network: 'testnet',
	baseUrl: 'https://fullnode.testnet.haneul.io:443',
}).$extend(haneulns());

// HaneulNS methods are now available under client.haneulns.
const nameRecord = await client.haneulns.getNameRecord('example.haneul');
```
</TabItem>

<TabItem label="Constants initializer" value='constants'>
```js
import { haneulns, type PackageInfo } from '@haneullabs/haneulns';
import { HaneulGrpcClient } from '@haneullabs/haneul/grpc';

const packageInfo: PackageInfo = {
	packageId: '0x...',
	packageIdV1: '0x...',
	// ... other required fields
};

const client = new HaneulGrpcClient({
	network: 'localnet',
	baseUrl: 'http://localhost:9000',
}).$extend(haneulns({ packageInfo }));
```

The `PackageInfo` type defines the required fields. For current Mainnet and Testnet values, see the [HaneulNS active constants](https://docs.haneulns.io/developer#active-constants), which HaneulNS maintains. Do not copy package IDs from documentation, because they change on every package upgrade.

</TabItem>
