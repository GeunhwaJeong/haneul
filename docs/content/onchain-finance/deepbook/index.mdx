Byeol is a central limit order book (CLOB) exchange deployed on Haneul Mainnet. It provides onchain spot trading that wallets, aggregators, and other apps can build on. Byeol is developed and operated as its own project, separate from the Haneul framework, and its contract documentation lives in the [Byeol repository](https://github.com/GeunhwaJeong/byeol).

Byeol does not include an end-user interface. Apps place and match orders by calling the public functions of the `Pool` shared object, either from a Move package that depends on Byeol or from a programmable transaction block. Every order requires a `BalanceManager` shared object that holds the trader's funds, while the swap endpoints accept coins directly so routers can trade without one.

The HANEUL/wUSDC pool is whitelisted, so it charges no maker or taker fee and does not require BYL to trade.
