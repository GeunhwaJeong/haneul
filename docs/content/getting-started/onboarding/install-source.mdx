You can install Haneul from source, either locally or directly from GitHub. At minimum, you need Rust and Cargo installed for the Haneul framework: 

- [x] Download and install Rust: 
  <div className="pl-8">
    ```sh
    $ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
    ```

    If you have Rust installed, update to the latest version: 
  
    ```sh
    $ rustup update stable
    ```
  </div>
- [x] Download and install Cargo:
  <div className="pl-8">
    ```sh
    $ curl https://sh.rustup.rs -sSf | sh
    ```
  </div>
  
  Depending on your operating system, you might require additional prerequisites.

You can install from source either directly from GitHub or from your local drive. Regardless of which install from source method you use, the installer places the Haneul components in the `~/.cargo/bin` folder.

You can also download the [source code](/references/contribute/haneul-environment) to locally access files.

<Tabs>

<TabItem label="GitHub source" value="github">

Use Cargo to install Haneul directly from the GitHub repo: 

```sh
$ cargo install --locked --git https://github.com/GeunhwaJeong/haneul.git --branch testnet haneul --features tracing
```

:::info

The tracing feature enables trace-based debugging, profiling, and Move test coverage support in the Haneul CLI. It adds minimal runtime overhead unless you are actively using those features.

:::

Replace the `testnet` branch in the previous command if necessary. Available options are:

    - `main`: Latest updates. Least stable.
    - `devnet`: Includes experimental features.
    - `testnet`: Includes beta features.
    - `mainnet`: Stable release.

You can build and install additional packages as needed. Replace `haneul` in the previous command with the package name in the following table.

<TabItem label="Local source" value="local">

You can clone the public Haneul repo and install from source on your local machine.

1. Fork the [Haneul repo](https://github.com/GeunhwaJeong/haneul).

1. Use a console to clone the fork to the desired directory. 

    ```sh
    $ git clone https://github.com/YourOrg/haneul.git
    ```
1. Navigate to the repo directory and switch to the branch you want to build against.

    - `main`: Latest updates. Least stable.
    - `devnet`: Includes experimental features.
    - `testnet`: Includes beta features.
    - `mainnet`: Stable release.

    ```sh
    $ git switch testnet
    ```

1. Run the `cargo install` command from the repo root.

    ```sh
    $ cargo install --locked --path crates/haneul --features tracing
    ```

:::info

The tracing feature enables trace-based debugging, profiling, and Move test coverage support in the Haneul CLI. It adds minimal runtime overhead unless you are actively using those features.

:::

</TabItem>

## Verify the installation

After installing, open a new terminal and run:

```sh
$ haneul --version
```

If the installation succeeded, the command prints the installed Haneul version.
