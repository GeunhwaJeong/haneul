The Haneul MCP server provides AI coding assistants with direct access to Haneul developer documentation and other important source material such as blogs, GitHub source code, and example apps. The Haneul MCP server does not use data cached longer than a few hours, so your agent has access to the most up to date content when referencing the MCP server. Other agents may cache source information for several weeks before crawling an updated version, leading to instances where a feature may be released on Mainnet but your agent isn't aware of it. 

You connect the server to your IDE so your AI assistant can search and retrieve Haneul documentation without leaving your editor.

The server is hosted at `https://haneul.mcp.kapa.ai` and exposes 2 tools:

- **`search_haneul_knowledge_sources`:** Searches across all Haneul documentation and returns ranked results with source URLs and content.

- **`get_haneul_knowledge_documents`:** Fetches full documents by exact URL for deeper context.

## Connect the Haneul MCP server

<Tabs groupId="ide">

<TabItem value="claude-code" label="Claude Code">

Run the following command in your terminal:

```sh
$ claude mcp add --transport http haneul-docs https://haneul.mcp.kapa.ai
```

Start Claude Code and run `/mcp` to verify the connection. Authenticate through your browser when prompted ([Kapa MCP docs](https://docs.kapa.ai/integrations/mcp/overview)).

</TabItem>

<TabItem value="cursor" label="Cursor">

Create or update the `.cursor/mcp.json` file in your project root with the following configuration:

```json
{
  "mcpServers": {
    "haneul-docs": {
      "type": "http",
      "url": "https://haneul.mcp.kapa.ai"
    }
  }
}
```

Restart Cursor to load the new MCP server. Authenticate through your browser when prompted ([Kapa MCP docs](https://docs.kapa.ai/integrations/mcp/overview)).

</TabItem>

<TabItem value="vscode" label="VS Code">

Create or update the `.vscode/mcp.json` file in your project root with the following configuration (requires VS Code 1.102 or later with GitHub Copilot):

```json
{
  "servers": {
    "haneul-docs": {
      "type": "http",
      "url": "https://haneul.mcp.kapa.ai"
    }
  }
}
```

Restart VS Code to load the new MCP server. Authenticate through your browser when prompted ([Kapa MCP docs](https://docs.kapa.ai/integrations/mcp/overview)).

</TabItem>

</Tabs>

## Authentication

The Haneul MCP server uses OAuth authentication through Google or GitHub. When you connect for the first time, your IDE opens a browser window for authentication. After you authenticate, the server associates your identity with rate limits ([Kapa MCP overview](https://docs.kapa.ai/integrations/mcp/overview)).

## Rate limits

The server enforces per-user rate limits ([Kapa MCP overview](https://docs.kapa.ai/integrations/mcp/overview)):

| **Tool** | **Per-user daily limit** |
|---|---|
| `search_haneul_knowledge_sources` | 300 requests per day |
| `get_haneul_knowledge_documents` | 300 requests per day |

## Verify the connection

After configuring the MCP server, verify that your IDE can access it:

1. Open your AI assistant in the IDE.
2. Ask a question about Haneul development (for example, "How do programmable transaction blocks work on Haneul?").
3. Confirm that the assistant references Haneul documentation in its response.

If the connection fails, check that the URL `https://haneul.mcp.kapa.ai` is accessible from your network and that you completed the browser authentication step.
